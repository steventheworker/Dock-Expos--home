Custom bottom bar and Recents Editor

macOS 27 no longer displays App Exposé's former recent documents and minimized windows bar. Dock Exposé supplies a custom replacement.

Using it

  • On macOS 27 it is enabled by default in App Exposé.
  • On macOS 26 it can be enabled in Preferences.
  • Press fn+R to toggle the bar manually, even when App Exposé is closed.
  • The status-item menu contains the same Recents Editor command.

Contents

The bar can show recent documents and minimized windows for the relevant application. Click an item to open or restore it. Hover an item to remove a recent document or close a minimized window.

Full Disk Access is required for recent-document reading and editing. Screen Recording is required for minimized-window thumbnails; without it, thumbnails may be blank.
